# Nano Banana 2 prompts — Innovation page imagery

Three prompts for the three conceptual innovation tiles. Paste each into Nano Banana 2
(Gemini 3.1 Flash Image), then save the outputs to this directory with the exact filenames below.

**Shared design intent:** these three sit as a cohesive set on a DARK page
(background `#151a16`), in framed 4:3 tiles, next to a fourth tile (the SWIFT product logo).
So they are deliberately **dark, abstract, tech-forward** — NOT the white-background
brochure style. Public-safe: NO identifiable hardware, NO device close-ups, NO named
equipment, NO text/labels baked into the image.

Filenames (all 4:3, 2K, save as .jpg):
- `sensing-vision.jpg`
- `sentia.jpg`
- `alt-comms.jpg`
(SWIFT tile is the supplied logo → `swift.jpg`, handled separately.)

---

## 1 — sensing-vision.jpg

```
Create an abstract, dark, tech-forward concept image for Anywise — an Australian
defence and government technology consultancy. The theme is distributed low-power
sensing at the edge: many small sensing nodes spread across a wide, remote dark
landscape, each emitting a soft glowing detection pulse, connected by faint signal
lines, turning a dark blind-spot environment into a live picture.

Style: abstract and atmospheric, NOT literal — do not show any identifiable devices,
cameras, circuit boards, or branded hardware. Suggest sensing through glowing nodes,
concentric detection rings, and thin connecting lines over a dark terrain silhouette.

Brand requirements:
- Dark background, near-black with a deep Mint (#2d7f36) undertone
- Glowing nodes and detection pulses in Apple green (#39a849)
- A few brighter Lime (#c3e01b) accent highlights on key nodes
- Clean, flat, modern, professional; generous negative space; no clutter
- No text, no labels, no logos, no people, no stock photography
- Subtle plus-sign (+) motifs may appear faintly among the nodes as a decorative pattern

Format: 4:3 aspect ratio, 2K resolution.
Cinematic, high quality, cohesive as part of a set of three dark abstract tech images.
```

## 2 — sentia.jpg

```
Create an abstract, dark, tech-forward concept image for Anywise — an Australian
defence and government technology consultancy. The theme is an intelligence ecosystem
that turns scattered raw data into a single trusted decision: fragmented data points
on one side flowing left-to-right through a refining pipeline and converging into one
clear, bright focal point of decision on the other side.

Style: abstract data-flow visualisation — flowing particles, nodes and connecting
pathways that start chaotic and scattered, then organise and converge into a single
strong point of light. Suggest six subtle stages along the flow without any text.
Do NOT show screens, dashboards, faces, or hardware.

Brand requirements:
- Dark background, near-black with a deep Mint (#2d7f36) undertone
- Data particles and pathways in Apple green (#39a849)
- The converging decision focal point glowing bright Lime (#c3e01b)
- Clean, flat, modern, professional; sense of order emerging from complexity
- No text, no labels, no logos, no people, no stock photography

Format: 4:3 aspect ratio, 2K resolution.
Cinematic, high quality, cohesive as part of a set of three dark abstract tech images.
```

## 3 — alt-comms.jpg

```
Create an abstract, dark, tech-forward concept image for Anywise — an Australian
defence and government technology consultancy. The theme is resilient, self-healing
communications in a contested environment: a mesh network of glowing nodes where
signal reroutes dynamically around gaps and obstacles, data finding a path through
when direct routes are blocked.

Style: abstract network mesh — interconnected glowing nodes and links across a dark
field, with some links shown breaking/faded and the signal visibly rerouting along
alternative glowing paths around a dark obstacle mass. Suggest resilience and
redundancy. Do NOT show antennas, radios, satellites, or identifiable hardware.

Brand requirements:
- Dark background, near-black with a deep Mint (#2d7f36) undertone
- Active mesh links and nodes in Apple green (#39a849)
- The successful rerouted path highlighted in bright Lime (#c3e01b)
- Broken/inactive links shown dim/faded, not red
- Clean, flat, modern, professional; generous negative space
- No text, no labels, no logos, no people, no stock photography
- A subtle upward-arrow (↑) motif may appear faintly as a decorative element

Format: 4:3 aspect ratio, 2K resolution.
Cinematic, high quality, cohesive as part of a set of three dark abstract tech images.
```

## Iteration tips
- If an image comes out too bright/white: "Make the background much darker, near-black with a deep green undertone; reduce overall brightness."
- If too literal/hardware-like: "Make it more abstract and conceptual — remove any recognisable devices, use only glowing nodes, particles and connecting lines."
- To tie the set together: paste an approved one as a reference image and say "Generate in the same visual style and palette as this reference image."
